# SortBy

Which response parameter to sort by. **Possible values**: `api_key`, `created_at`, `name`, `enabled`.


## Example Usage

```csharp
using Cloudinary.Account.Provisioning.Models.Requests;

var value = SortBy.ApiKey;
```


## Values

| Name        | Value       |
| ----------- | ----------- |
| `ApiKey`    | api_key     |
| `CreatedAt` | created_at  |
| `Name`      | name        |
| `Enabled`   | enabled     |
