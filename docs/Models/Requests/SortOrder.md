# SortOrder

Control the order of returned keys. **Possible values**: `desc` (default), `asc`.


## Example Usage

```csharp
using Cloudinary.Account.Provisioning.Models.Requests;

var value = SortOrder.Desc;
```


## Values

| Name   | Value  |
| ------ | ------ |
| `Desc` | desc   |
| `Asc`  | asc    |
