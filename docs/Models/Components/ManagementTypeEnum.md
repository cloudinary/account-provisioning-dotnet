# ManagementTypeEnum

Specifies whether the role's policies are managed by Cloudinary (`system`) or by the user (`custom`).

## Example Usage

```csharp
using Cloudinary.Account.Provisioning.Models.Components;

var value = ManagementTypeEnum.System;
```


## Values

| Name     | Value    |
| -------- | -------- |
| `System` | system   |
| `Custom` | custom   |
