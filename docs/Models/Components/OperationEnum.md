# OperationEnum

Specifies the operation to perform. Use `add` to associate or `remove` to disassociate.

## Example Usage

```csharp
using Cloudinary.Account.Provisioning.Models.Components;

var value = OperationEnum.Add;
```


## Values

| Name     | Value    |
| -------- | -------- |
| `Add`    | add      |
| `Remove` | remove   |
